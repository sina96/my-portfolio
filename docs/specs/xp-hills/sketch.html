Painting a hill in 25,000 pixels

Some desktop wallpapers stick with you: a soft green hill, a deep blue sky and a few lazy clouds. This page's header is a love letter to that kind of picture. It's drawn on a grid of only 200 by 125 cells, and each cell is blown up to an 8-pixel square.

Nothing in it is a bitmap file. When the page loads, a small script paints the sky, the hills and the clouds into tiny canvases. The browser then stretches them with image-rendering: pixelated so every cell stays a crisp square.

Gradients without gradients

A pixel-art palette only has a handful of colours, so how do you get a sky that fades from deep blue to almost white? You cheat with ordered dithering. Every cell compares how far it sits between two palette colours with a value from a small, repeating 4×4 threshold grid, called a Bayer matrix. If it's past the threshold, it takes the lighter colour.

const BAYER = [[0, 8, 2, 10], [12, 4, 14, 6], [3, 11, 1, 9], [15, 7, 13, 5]];
const th = (x, y) => (BAYER[y & 3][x & 3] + 0.5) / 16;

const pick = (pal, t, x, y) => {
  const f = t * (pal.length - 1), i = Math.floor(f);
  return pal[(f - i) > th(x, y) ? i + 1 : i];
};

One curve, two moods

The big hill is a single function: a bell curve that's narrower on the left than on the right, plus a tiny sine wobble so the ridge doesn't look machine-made. Light comes from the upper left, so the shade gets darker the further down and to the right a cell sits. The top row of the ridge is lit an extra step to catch the sun.

The trick to good pixel art isn't more pixels. It's deciding which ones matter.

Switch your system to dark mode and the same curve turns into a night scene. The palette swaps to dark greens and navy, a moon appears, and the grass glints become fireflies.

Motion that snaps

Smooth motion would give the game away. Every cloud moves with steps() timing, so it jumps exactly one cell at a time. Higher, smaller clouds move more slowly than the big low ones, which gives a cheap sense of depth. Cloud shadows slide over the hill through an SVG mask, so they never spill into the sky.

  • 7 clouds by day and 3 by night, each with its own speed and starting offset
  • 2 cloud shadows, masked to the front hill
  • Around 70 blinking grass glints, or fireflies after dark
  • No animation at all when your system asks for reduced motion

From wallpaper to header

On a wide screen the scene fills the whole window at first. As you scroll, it shrinks. Its bottom edge stays attached to the top of this article and fades softly into the indigo page, until all that's left is a header strip that scrolls away with the text. On a phone, it's simply a header from the start.
