# XP Hills redesign

## 2026-11-20

- Replaced the Windows 98 navigation with an XP taskbar, Start menu, and restorable windows.
- Added deterministic day and night hills, a desktop scroll transition, and a static scene for mobile and reduced motion.
- Added the `hi.exe` desktop window, reopen icon and one-time tray tip, plus an Explorer task pane that appears below the hills (a drawer on mobile).
- Updated the site to XP-era font stacks, merged post content into one window, and gave the 404 an XP error window over the hills.
- Made the landing teaser translucent and added a two-state desktop scroll glide. Centred overlapping windows and moved sub-page navigation into the windows themselves.
- Added static blog and contact routes, preserved old tab links with redirects, and restyled blog, CV, availability, and 404 pages.
- Aligned the landing glide with About me, added a Luna Night mode switch and a one-time mobile menu hint, and restored Contact’s on-demand availability.
- Added a pixel-art Contact desk, a configurable status dot, a scenery mode, and a smaller RSS link.
- Rebuilt the CV as a WordPad document with a responsive résumé, A4 printing, PDF actions, and phone-free Markdown copying.
- Made scenery mode responsive: a viewport-sized pixel grid, a moon that stays in view on phones, and a one-time reveal that resize no longer replays.
- Landing Home now restores closed windows and glides to the content on desktop or returns to the hills on mobile. Every visit to `/` starts at the hills.
- Gave the Contact desk a tiny code-editor screen and an About me–style layout on desktop, quieted the `hi.exe` note, and added Home and mobile labels to the WordPad toolbar.
- Added sitemap, social previews, structured data, and full-content RSS.
- Upgraded Next.js to 16.4.6 and sanitize-html to 2.18.2 for security advisories.
- Hardened security: admin refuses placeholder or short passwords, the availability API caches calendar fetches, public pages enforce a Content-Security-Policy, and the Markdown sanitizer is stricter.
- Replaced the CV and its PDF with the updated résumé; the WordPad page now supports Core Skills, a Languages list, and `###` job entries.
- Added ESLint, TypeScript, and Vitest CI checks; centralized admin auth and pinned Sveltia CMS with integrity verification.
